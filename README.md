# Pokédex - Consumo da PokéAPI

Projeto desenvolvido para a disciplina de **Laboratório de Linguagens de Programação**.

O objetivo do trabalho foi desenvolver uma aplicação web capaz de consumir uma API REST externa, utilizando a **PokéAPI**, disponível em:

https://pokeapi.co/

A aplicação funciona como uma Pokédex, permitindo consultar e visualizar informações de diferentes Pokémon.

## Funcionalidades

A aplicação permite:

- Buscar Pokémon por nome ou número;
- Exibir a arte oficial do Pokémon;
- Exibir os tipos do Pokémon;
- Exibir altura e peso;
- Exibir habilidades;
- Exibir os valores base das estatísticas;
- Filtrar Pokémon por tipo;
- Utilizar dois tipos simultaneamente como filtro;
- Navegar pelos Pokémon através de paginação;
- Comparar dois Pokémon lado a lado;
- Tratar pesquisas de Pokémon inexistentes.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML5;
- CSS3;
- JavaScript;
- API REST;
- Fetch API;
- PokéAPI.
